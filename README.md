# منصة تسيير وحدة إنتاج زيت الزيتون البدر

نسخة التطوير الأولى (v0.1) لمنصة داخلية لإدارة معصرة الزيتون، مبنية على Next.js وTypeScript وSupabase/PostgreSQL.

## المعطيات المعتمدة
- اسم الوحدة: **وحدة إنتاج زيت الزيتون البدر**.
- تعريفة الطحن الابتدائية: **0.70 درهم لكل كيلوغرام**.
- زيت كل زبون يسجّل باسمه بصورة مستقلة.
- لا يُعامل زيت الزبائن كمخزون مملوك للمعصرة أو كإيراد لها.

## ما تحتويه هذه النسخة
- لوحة قيادة عربية RTL ومتجاوبة.
- خريطة وحدات العمل الرئيسية.
- حاسبة تقديرية لتكلفة الطحن تعمل محلياً.
- مخطط أولي لقاعدة بيانات PostgreSQL مع العملاء، أوزان الاستقبال، دفعات الطحن، مخزون الزيت، الحركات، الوصولات، الحسابات، المصاريف وسجل التدقيق.

**مهم:** المؤشرات في لوحة القيادة لا تعرض أرقاماً تجريبية على أنها بيانات حقيقية. الحاسبة لا تنشئ سجلاً محاسبياً. هذه النسخة ليست جاهزة للإنتاج ولا ينبغي إدخال معاملات حقيقية قبل استكمال تسجيل الدخول، سياسات RLS، وإجراءات قاعدة البيانات الذرية واختبارات الصرف والتسوية.

## التشغيل محلياً
1. ثبّت Node.js 20 أو أحدث.
2. شغّل `npm install`.
3. شغّل `npm run dev` ثم افتح `http://localhost:3000`.

## ربط Supabase لاحقاً
1. أنشئ مشروع Supabase منفصلاً للاختبار.
2. راجع `supabase/schema.sql` وطبّقه في بيئة الاختبار بعد المراجعة.
3. انسخ `.env.example` إلى `.env.local` وأدخل عنوان المشروع ومفتاح `anon` العام.
4. أضف تسجيل الدخول وسياسات RLS وعمليات RPC الحساسة قبل نشر النظام.

**الأمان:** لا تضع مفتاح `service_role` في المتصفح أو GitHub. لا تخزّن كلمات المرور كنص صريح. يجب أن تكون عمليات التسليم، صرف المخزون، والأداءات معاملات ذرية في قاعدة البيانات مع منع تكرار الصرف وسجل تدقيق.

## مراحل التنفيذ المقترحة
1. تأسيس قاعدة البيانات والدخول والإعدادات.
2. الزبائن واستقبال الزيتون والوزن وطابور الانتظار.
3. دفعات الطحن وتوزيع الإنتاج باسم كل زبون.
4. المخزون ووصولات التسليم ومنع الصرف المكرر.
5. المبيعات والصندوق والتسبيقات والديون والمصاريف.
6. العمال والصيانة والجودة والتقارير، ثم اختبار الاسترجاع والنسخ الاحتياطي.

# وحدة إنتاج زيت الزيتون البدر — واجهة HTML

## الملفات
- `index.html`: الواجهة العربية RTL.
- `css/style.css`: التصميم المتجاوب للهاتف والحاسوب.
- `js/app.js`: تنقل الصفحات ومعاينة الحسابات وسجل جلسة تجريبي مؤقت.
- `supabase/schema.sql`: ملف تأسيس قاعدة البيانات، يجب مراجعته وتنفيذه في مشروع Supabase مخصص.

## التشغيل التجريبي
افتح `index.html` في متصفح حديث أو انشر محتويات هذا المجلد بوصفه موقعًا ثابتًا على Vercel.

## تنبيه
هذه النسخة واجهة تأسيسية وليست نظامًا تشغيليًا جاهزًا. سجل الوصولات الحالي محفوظ في ذاكرة الصفحة فقط، ولا يوجد اتصال بقاعدة البيانات أو تسجيل دخول أو صلاحيات أو نسخ احتياطي. لا تستخدمها لتسجيل بيانات تشغيل حقيقية قبل بناء ربط Supabase وتأمينه واختبار عمليات المخزون والحسابات.

## النشر
عند استخدام GitHub + Vercel، يجب أن يكون `index.html` و`css/` و`js/` في جذر المشروع المختار. لا يحتاج الموقع الثابت إلى `package.json` أو Next.js.

# Société Albadr — منصة إدارة معصرة زيت الزيتون

واجهة عربية RTL متعددة الصفحات، متجاوبة للهاتف والحاسوب، بهوية خضراء وذهبية. تشمل لوحة القيادة والاستقبال والوزن اليدوي/مكان تهيئة الوزن الإلكتروني والإنتاج والمخزون والأداءات ووصولات التسليم وبيع زيت المعصرة والعمال والأجور والمالية والمصاريف والموردين والتقارير والإعدادات.

## النشر على Vercel
- ارفع محتويات هذا المجلد إلى مستودع GitHub ثم اربطه بـ Vercel كـ Static Site.
- لا يلزم `package.json` لتشغيل هذه الصفحات.
- ضع اللوغو في `assets/images/societealbadr.jpg`.

## الوضع الحالي
هذه نسخة واجهة متعددة الملفات قابلة للتطوير. النماذج تُظهر معاينة وتتحقق من بعض المدخلات، لكنها **لا تحفظ في Supabase بعد**، ولا تقرأ الميزان فعليًا. لا تستخدمها لتسجيل معاملات حقيقية قبل إتمام الربط والحماية.

## الخطوات التالية
1. مطابقة كل نموذج مع الأعمدة الفعلية في Supabase الحالي.
2. إعداد Supabase Auth وسياسات RLS للمالك المخول فقط؛ لا تمنح `anon` وصولًا عامًا إلى بيانات المعصرة.
3. تنفيذ عمليات قاعدة بيانات ذرية لأرقام الوصولات والتسليم والمخزون.
4. إكمال العمال والحضور والأجور ومبيعات زيت المعصرة والمشتريات.
5. ربط الميزان بحسب الماركة والموديل والمنفذ (Bluetooth/USB/RS-232).
6. اختبار النسخ الاحتياطي والطباعة والجوال قبل الإنتاج.
